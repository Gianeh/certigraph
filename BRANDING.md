# CertiGraph branding

## Tagline

Do not trust the solver. Verify the result.

## Short description

Proof-carrying graph results for untrusted and AI-generated solvers.

## Long description

CertiGraph is a small dependency-free Python toolkit for certifying graph results. It lets producers emit an answer plus a certificate, then validates that evidence with an independent checker.
